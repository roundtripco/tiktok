# بوت مكاتب العقار (المرحلة ١)

بوت تيليجرام يخدم مكاتب العقار في الكويت باشتراك شهري. كل مكتب يسجّل مرة وحدة، ويضيف وسطاءه برابط.

## الخدمات

| الخدمة | وش يسوي الوسيط | وش يرجع له |
|---|---|---|
| 🏠 بطاقة عقار | يختار نوع العقار ويكتب التفاصيل ويرسل ١–٥ صور | صورة 1080×1350 جاهزة للواتساب والانستقرام، وملف PDF، ونص جاهز للنسخ |
| 🧾 سند قبض | الاسم والمبلغ والسبب وطريقة الدفع | سند PDF مرقّم بشعار المكتب، والمبلغ مكتوب بالحروف |
| 👥 المستأجرين | يسجّل المستأجر مرة وحدة | تذكير قبل الاستحقاق بـ ٣ أيام، ويوم الاستحقاق، وإذا تأخر، مع زر رسالة واتساب جاهزة وزر «تم الدفع» يطلّع السند تلقائياً |
| ⚙️ المكتب | — | تعديل الاسم والرقم والشعار واللون، وإدارة الوسطاء، وتجديد الاشتراك |

## الاشتراك
- تجربة مجانية (`TRIAL_DAYS`، الافتراضي ١٤ يوم) تبدأ من التسجيل.
- لما ينتهي الاشتراك تتوقف الخدمات والتذكيرات.
- روابط UPay تنتهي بعد ٢٤ ساعة، فصاحب المكتب يضغط «💳 اطلب رابط الدفع»، ويوصل للمدير طلب فيه زر «📎 أرسل رابط الدفع». المدير يسوي رابط من UPay ويلصقه، والبوت يرسله للمكتب.
- صاحب المكتب يدفع ويضغط «✅ دفعت»، فيوصل للمدير تنبيه فيه أزرار التفعيل (١ أو ٣ أو ١٢ شهر).
- أوامر المدير: `/admin` يعرض التقرير، و`/activate كود_المكتب عدد_الأشهر` يفعّل الاشتراك، و`/sendlink كود_المكتب الرابط` يرسل رابط دفع مباشرة.
- إذا صار عندك رابط دفع دائم، حطه في `UPAY_LINK` ويطلع للمكاتب مباشرة بدل الطلب.
- البوت ينبّه صاحب المكتب قبل انتهاء الاشتراك بـ ٣ أيام، ويوم الانتهاء، وبعده بيوم.

## لوحة التحكم
صفحة على المتصفح للمدير فيها:
- ملخص: المكاتب الفعالة، المشتركين، دخل الشهر، الدخل المتوقع
- **بانتظارك:** طلبات روابط الدفع، والمكاتب اللي تقول إنها دفعت (مع زر تفعيل مباشر)
- الاشتراكات اللي تنتهي خلال ٧ أيام
- جدول كل المكاتب مع بحث وفلترة حسب الحالة، واستخدام كل مكتب آخر ٣٠ يوم
- صفحة لكل مكتب: تفعيل اشتراك، إرسال رابط دفع، تمديد التجربة، رسالة لصاحب المكتب، وسجل الاشتراك
- رسالة جماعية للمكاتب

**الدخول:** اكتب `/dashboard` في البوت، ويوصلك رابط صالح ١٥ دقيقة ولمرة وحدة. الجلسة تبقى ٧ أيام.
**الإعداد:** `DASHBOARD_URL` و`DASHBOARD_PORT` في `.env`، وافتح المنفذ في جدار الحماية (`ufw allow 8081/tcp`).
⚠️ اللوحة حالياً على HTTP عادي. لما يصير عندك دومين، نحط HTTPS قبل ما يكبر عدد المكاتب.

## التشغيل على الـ VPS
```bash
git clone <repo> && cd <repo>/aqar-bot
sudo bash deploy/install.sh          # يثبّت Python وChromium وخدمة systemd
sudo nano /opt/aqar-bot/.env          # BOT_TOKEN و ADMIN_IDS و UPAY_LINK
sudo systemctl restart aqarbot
journalctl -u aqarbot -f              # متابعة السجل
```
قاعدة البيانات والشعارات تنحفظ في `/opt/aqar-bot/data/`. هذا المجلد هو اللي تاخذ منه نسخة احتياطية.

## التجربة محلياً بدون تيليجرام
```bash
pip install -r requirements-dev.txt && playwright install chromium
python -m pytest                                   # ٩ اختبارات تشمل سيناريو مكتب كامل
AQAR_SAMPLES_DIR=samples python -m pytest          # يحفظ عينات البطاقة والسند في samples/
```
`tests/fake_telegram.py` يحاكي خوادم تيليجرام، فالسيناريو يمشي على البوت الحقيقي من التسجيل لين التجديد.

## هيكل الكود
```
aqarbot/
  app.py          تجميع البوت والمهمة اليومية
  db.py           قاعدة البيانات SQLite
  documents.py    تجهيز البطاقة والسند
  render.py       تحويل HTML إلى صورة وPDF (Chromium)
  jobs.py         تذكير الإيجارات وتنبيهات الاشتراك
  utils.py        المبالغ بالدينار، المبلغ بالحروف، التواريخ، الهواتف
  handlers/       المحادثات: التسجيل، البطاقة، السند، المستأجرين، المكتب
  templates/      قوالب البطاقة والسند
  fonts/          خط Tajawal (رخصة OFL)
```

## التسويق (المرحلة ٢)
```
marketing/outreach.md     رسائل التواصل مع المكاتب، والردود على الاعتراضات، ونص منشور الفيديو
marketing/make_video.py   يصنع الفيديو التعريفي (عمودي ٣٠ ثانية) من عينات البوت
site/                     صفحة الخدمة مع الفيديو والعينات
```
لإعادة صنع الفيديو: `python marketing/make_video.py` (يحتاج ffmpeg)، والفيديو يطلع في `marketing/out/demo.mp4`.
رابط البوت في الصفحة يتعبّى من `BOT_USERNAME` آخر `site/index.html`.
